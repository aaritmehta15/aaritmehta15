## 💼 Experience

### AI Voice Agent Developer — Futwork

**Oct 2025 – Dec 2025**

Worked on the **end-to-end development of a client-ready voice AI agent**, combining modern generative AI with real-time backend systems.

* 🎙️ Built a voice AI agent using **Google Gemini 2.5 Flash Native Audio** and **Google ADK**, enabling direct speech-to-speech interaction.
* ⚡ Architected a **low-latency, two-way voice streaming pipeline** over WebSockets using the Google Gemini API.
* 🔌 Integrated the AI system with the **Futwork Voice Plugin** for real-world client deployment.
* 🧠 Designed dynamic system instructions that adapted the agent's behaviour based on the conversation.
* 🛡️ Implemented fallback and termination logic to handle repeated user rejection gracefully.

This experience gave me hands-on exposure to an important side of AI engineering: **taking a model and turning it into an actual interactive system**.
